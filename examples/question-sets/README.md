# Industry question sets

- [Industrial equipment](industrial-equipment.json): supplier selection, custom
  dimensions, training, and maintenance evidence.
- [SaaS](saas.json): workflow selection, integrations, security, onboarding, and
  cost questions.

Each set has five intent questions and one brand question. Acme Widgets and
`acme-widgets.example` are fictional placeholders in two independent scenarios.
The questions do not assert that any product or capability actually exists.
There are no collected answers or measurement results in these files.

Copy the `questions` array into a private results file and choose the actual
market, language, audit date, engine coverage, and session conditions before
collecting evidence. Replace the fictional identity privately. Use the
[manual worksheet](../../templates/manual-worksheet.md) without paid tools.
These question sets are not complete results files and cannot be passed directly
to the scorecard command.

Keep IDs and exact wording stable across repeat audits; record edits and locale
changes. Use only one set per results file unless you assign new, unique IDs.
Save answers and citations before assigning mention status. Record failed and
unattempted observations separately; never fill missing evidence with guesses.
